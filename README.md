# Expense Tracker

A simple Python-based Expense Tracker that helps users record, manage, and track their daily expenses.

## Features

- Add new expenses
- View all recorded expenses
- Edit existing expenses
- Delete expenses
- Calculate category-wise totals
- Calculate monthly expenses
- Input validation
- Store expense records using JSON

## Technologies Used

- Python
- JSON
- PyCharm

## Project Structure

```text
Expense_tracker/
│
├── main.py
├── expenses.json
├── README.md
└── .gitignore
```

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## Data Storage

Expense records are stored in `expenses.json`, allowing data to remain available even after closing the program.
